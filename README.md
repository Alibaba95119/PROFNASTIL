# IT-АРХИТЕКТОР — Лендинг для автоматизации производства

Лендинг для компании, специализирующейся на автоматизации производства профнастила и металлочерепицы на базе 1С.

## 📋 О проекте

Одностраничный сайт (landing page) для презентации услуг по автоматизации производственных процессов. Сайт содержит информацию об услугах, преимуществах, процессе работы, отзывах клиентов, FAQ и форму обратной связи.

### Основные разделы

- **Hero** — первый экран с призывом к действию
- **Услуги** — 9 причин выбрать компанию и описание услуг
- **Процесс работы** — пошаговое описание взаимодействия
- **Отзывы** — карусель с отзывами клиентов
- **FAQ** — часто задаваемые вопросы
- **Контакты** — контактная информация и форма обратной связи

## 🛠 Технологии

- **HTML5** — семантическая разметка
- **CSS3** — стилизация, адаптивный дизайн, анимации
- **JavaScript (ES6+)** — интерактивность, валидация форм, карусель
- **Google Fonts** — шрифт Inter
- **Google Forms** — backend для отправки заявок (без собственного сервера)
