# IT-АРХИТЕКТОР — Лендинг для автоматизации производства
Одностраничный сайт (лендинг) для продажи услуг сопровождения 1С с автоматизацией производства. Сайт адаптирован для всех устройств и содержит формы сбора заявок.

## 📋 Описание

Сайт предназначен для привлечения клиентов на услуги сопровождения 1С. Содержит информацию об услуге, преимуществах, процессе работы, отзывы клиентов, FAQ и форму для сбора заявок.

### Основные разделы

- **Решение** — первый экран с призывом к действию
- **Об услуге** — описание услуги автоматизации
- **Процесс работы** — пошаговое описание взаимодействия
- **Отзывы** — карусель с отзывами клиентов
- **FAQ** — часто задаваемые вопросы
- **Контакты** — контактная информация и форма обратной связи

## 🚀 Технологии

- **HTML5** — семантическая разметка
- **CSS3** — адаптивная верстка, анимации
- **JavaScript (ES6+)** — интерактивность, валидация форм, карусель
- **Google Forms** — backend для отправки заявок (без собственного сервера)
- **GitHub Pages** — хостинг

## 🔧 Настройка

### 1. Настройка Google Forms (для сбора заявок)

1. Создайте форму в Google Forms
2. Добавьте поля:
   - Тип формы
   - Имя
   - Телефон
   - Способ связи
   - Согласие на обработку
   - URL страницы
   - User Agent

3. В файле `js/script.js` найдите и замените:

```javascript
const FORM_ACTION_URL = 'ВАША_ССЫЛКА_НА_ФОРМУ';
const FIELD_IDS = {
    name: 'entry.XXXXXX',      // ID полей из вашей формы
    phone: 'entry.XXXXXX',
    contactMethod: 'entry.XXXXXX',
    privacy: 'entry.XXXXXX',
    pageUrl: 'entry.XXXXXX',
    userAgent: 'entry.XXXXXX'
};
Как получить ID полей: Откройте консоль (F12) → отправьте форму → вкладка Network → найдите formResponse → вверху увидите entry.XXXXXX
